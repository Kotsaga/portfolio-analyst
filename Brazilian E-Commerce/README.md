О проекте

Анализ данных бразильского маркетплейса Olist с целью изучения клиентского опыта, повторных покупок и факторов, связанных с удовлетворённостью покупателей.

Цель проекта: выявить проблемные аспекты клиентского опыта и сформулировать рекомендации для улучшения качества обслуживания.

Поставленные бизнес-вопросы:
1. Какая доля покупателей совершает более одного заказа? Отличаются ли оценки повторных покупателей от оценок клиентов с одной покупкой?
2. Как задержки доставки связаны с оценками покупателей? Как меняется доля низких оценок при увеличении задержки?
3. Какие категории получают наиболее низкие оценки и требуют дополнительного внимания?

Данные
Я использовала открытый датасет Brazilian E-Commerce Public Dataset by Olist на Kaggle.

Период данных: сентябрь 2016 — октябрь 2018 года.

В анализе использованы таблицы:
- Customers
- Orders
- Order Reviews
- Order Items
- Products

В процессе анализа были использованы следующие инструменты:
- Python
- Pandas
- NumPy
- Matplotlib
- Yandex DataLens

Основные результаты
- Доля покупателей, совершивших повторную покупку в рамках периода наблюдения, составила около 3%.
- Средняя оценка заказов, доставленных вовремя или раньше срока, — 4,29 из 5. Для заказов с задержкой — 2,57 из 5.
- Среди заказов с задержкой более 7 дней доля низких оценок (1–2) составила 78,32%. Для заказов, доставленных вовремя или раньше срока, — 9,19%.
- Среди категорий с достаточным количеством заказов наиболее низкую среднюю оценку получила категория moveis_escritorio — 3,64 из 5.

Выводы

1. В течение исследуемого периода повторный заказ совершили около 3% уникальных покупателей. Это указывает на низкую долю повторных покупок в рамках доступных данных, однако для оценки долгосрочной лояльности потребуется более длительный период наблюдения.
2. Чем больше задержка доставки, тем ниже оценки покупателей. Особенно заметна разница для заказов с задержкой более 7 дней: 78,32% таких заказов получили оценки 1–2, тогда как среди доставленных вовремя или раньше срока доля низких оценок составила 9,19%.
Дополнительно была изучена корреляция между длительностью задержки и оценкой покупателя. Коэффициент Пирсона составил −0,2669, коэффициент Спирмена — −0,1757. Оба значения указывают на отрицательную, но слабую связь между переменными.
3. Среди исследованных категорий наиболее низкая средняя оценка у moveis_escritorio — 3,64 из 5. Это направление заслуживает отдельного изучения с учётом количества заказов и отзывов покупателей.

Рекомендации

- Улучшить контроль доставки: проанализировать причины задержек, уделив особое внимание заказам с опозданием более чем на 7 дней. Отслеживать долю просроченных заказов и их связь с оценками покупателей.
- Изучить проблемные товарные категории: проверить отзывы, характеристики товаров и работу продавцов в категории moveis_escritorio, чтобы определить причины низких оценок.
- Исследовать повторные покупки: дополнительно проанализировать поведение клиентов после первого заказа, чтобы выявить факторы, влияющие на возвращение покупателей, и определить возможности для повышения их лояльности.
